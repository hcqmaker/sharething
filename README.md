### AutoExportPng.7z 
###### photoshop cc 2019 插件
> - 放置到 【Adobe Photoshop CC 2019\Required\CEP\extensions】下，
主要是自动导出png图片，方便绘制tileset图片，提供 
> 1. 间隔时间导出 
> 2. 保存文件时导出 
> 3. 点击按钮导出
> - 记得点击【获取导出路径】设置导出png的位置和名字，只有左边开着tiled，右边就绘制图片，之后就可以看效果了
