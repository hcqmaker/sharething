- game/PasserLost.7z my first game use urho3d + lua 
- out_png.jsx 是导出Png的小脚本ps cs6上测试使用, 目录放置到 Photoshop CS6\Presets\Scripts\out_png.jsx 之后重启ps在 文件-》脚本 列表里面就可以看到out_png啦
- 00_穴位图_多颜色.svg 十二经络图，中医穴位，包含任督二麦，加子午流注
- AutoExportPng.7z photoshop cc 2019 插件，放置到 【Adobe Photoshop CC 2019\Required\CEP\extensions】下，主要是自动导出png图片，方便绘制tileset图片，提供 1. 间隔时间导出 2. 保存文件时导出 3. 点击按钮导出，记得点击【获取导出路径】设置导出png的位置和名字，只有左边开着tiled，右边就绘制图片，之后就可以看效果了
